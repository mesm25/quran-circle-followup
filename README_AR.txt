ملفات صفحة نظام متابعة الحلقات القرآنية
1) index.html: الصفحة التعريفية.
2) preview.svg: صورة معاينة مناسبة للمشاركة.

قبل النشر:
- افتح index.html وابحث عن YOUR-GITHUB-USERNAME واستبدله باسم مستخدم GitHub الحقيقي في رابطَي og:image وtwitter:image.
- ارفع الملفين إلى جذر مستودع GitHub Pages.
- من Settings > Pages اختر Deploy from a branch ثم main و /(root).
- بعد نشر الصفحة، جرّب مشاركة الرابط. ظهور المعاينة في تطبيقات المحادثة قد يحتاج وقتًا لتحديث التخزين المؤقت.
ملاحظة: صفحة GitHub Pages ستكون عامة على الإنترنت. لا تضع فيها بيانات شخصية أو بيانات سرية.
